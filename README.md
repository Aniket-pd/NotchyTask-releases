# NotchyTask downloads

Official public installer downloads for NotchyTask, published by Aniket-pd.

Download the current Mac app from the [latest release](https://github.com/Aniket-pd/NotchyTask-releases/releases/latest).

This repository distributes application binaries and release notes. The application source code is maintained separately. Downloading an installer does not grant a paid feature license; activation remains inside the app.

Release assets are the existing signed distribution archives, with SHA-256 checksums provided for verification.
